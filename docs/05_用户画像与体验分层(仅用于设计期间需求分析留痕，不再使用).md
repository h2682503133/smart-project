# 智慧农业 - 用户画像与体验分层（定稿）

> 用途：供 **agent 个性化上下文**、**后端数据设计**、**前端体验设计**参考；**不进入权限模型，不影响系统架构**
> 系统边界：仅覆盖**生产域**（地块 / 设备 / 遥测 / 告警 / 控制 / 农事任务 / 种植标准）；**不做营收管理**（订单结算、租金、分红、成本核算均排除）

---

## 一、用户画像与特点分析

### 1.1 干系人与边界

| 角色 | 定位 | 说明 |
|---|---|---|
| 村集体经济组织 | 平台运营主体 | 系统所有者与运营者，负责运营、种植标准与知识资产维护、数据治理 |
| 农户（种植户） | 核心使用者 | 按经营模式分：**自主经营农户**（独立决策）与**订单农户**（按企业标准与权威文档执行）；经营模式差异不产生系统角色差异 |

**特点分析维度**：数字素养、决策依据偏好、信息需求、终端形态、任务卷入度。

### 1.2 生产者类画像

| 画像 | 特点分析 | 经营模式案例 |
|---|---|---|
| **自主经营农户** | 独立决策、自选生产资料；决策依据=经验+数据双轨；信息需求=标准粒度 | 自主经营 |
| **订单农户** | 按企业标准执行生产；决策依据=权威文档；信息需求=任务清单+标准对照 | 订单农业 |
| **经验型传统农户** | 高龄、经验驱动、数字素养低；决策依据=经验；终端=大字/极简；需语音交互 | 自主经营（自留地）；土地托管（托管方） |
| **技术型新型农户** | 年轻新农人、数据驱动；决策依据=数据趋势；信息需求=图表/对比；愿用工具 | 自主经营；合作社联合经营 |
| **规模经营主体** | 种植大户/家庭农场：多地块、雇工；决策依据=数据+进度；信息需求=多地块汇总 | 土地托管（受托经营方）；集体统一经营；反租倒包 |

### 1.3 管理类画像

| 画像 | 特点分析 | 经营模式案例 |
|---|---|---|
| **农场管理员** | 集体企业管理层：管多地块、做决策；信息需求=汇总看板、异常摘要、报表 | 集体统一经营；土地托管（集体托管运营） |
| **村级监管者** | 村干部：政策执行、数据监管、公示；信息需求=监管视图、统计口径 | 通用监管视角（覆盖全部模式） |
| **系统管理员** | 平台运维，不关注业务；信息需求=审计、监控、配置 | 不涉及经营模式 |

### 1.4 支持类画像

| 画像 | 特点分析 | 经营模式案例 |
|---|---|---|
| **农技员** | 农技推广/技术支持，知识库维护者；信息需求=知识管理、答疑工单 | 通用服务视角（覆盖全部模式） |
| **临时用工/雇工** | 只执行指派任务；信息需求=今日任务、步骤化指令；终端=移动端极简 | 集体统一经营（村集体雇工）；规模经营主体（大户雇工） |

### 1.5 经营模式归属（画像背景）

| 经营模式 | 所属画像 | 增量 |
|---|---|---|
| 自主经营 | 自主经营农户、技术型新型农户、规模经营主体、经验型传统农户 | 零增量（生产域基线） |
| 订单农业 | 订单农户 | agent 增量（权威文档 + 标准版本） |
| 土地托管 | 规模经营主体（受托）、农场管理员（集体运营）、传统农户（托管方） | agent 增量（经营身份视角） |
| 集体统一经营 | 农场管理员、临时用工、村级监管者 | agent 增量（任务类问答） |
| 合作社联合经营 / 反租倒包 | 技术型新型农户 / 规模经营主体 | 零增量 |
| 农事服务外包 | 边界外（引入第三方角色，不入系统） | 排除 |

## 二、系统建议

### 2.1 对 agent 的建议

| 建议 | 内容 |
|---|---|
| **语言风格注入** | 按用户 `interaction_style` 标签（通俗口语 / 标准口语 / 专业术语）在 Prompt 中注入 system 风格约束；前端不处理语言风格 |
| **决策依据偏好** | 按 `knowledge_reliance` 标签调整引用权重：经验型→经验+数据佐证；订单农户→强引用权威文档；新农人→数据趋势+可追问细节 |
| **经营身份注入** | 按经营模式注入回答视角：订单农户→SOP/检查清单式、关联种植标准版本；托管受托方→任务执行/生产进度视角；托管农户→自家地块生产状况；管理员→任务派发、异常摘要类问答 |
| **Prompt 预算分级** | 现场数据 > 知识库 > 短期窗口 > 长期记忆，超预算按此优先级裁剪 |
| **边界约束** | 只读业务数据、只给建议、**不提供设备控制工具**；只回答生产域问题，营收/结算/价格类问题拒绝回答或引导到系统外 |
| **权威文档准入** | 仅检索 ACTIVE（审核通过且当前版本）的知识文档，版本切换原子 |

### 2.2 对后端的建议

| 建议 | 内容 |
|---|---|
| **用户元数据标签** | 用户资料存 `ui_preference`（密度层级）、`interaction_style`（语言风格）、`knowledge_reliance`（决策依据偏好），供 agent 与前端读取 |
| **画像不进权限模型** | 画像仅是个性化参考层，不产生新角色，角色/权限/数据隔离维持修订版模型（农户/农场管理员/系统管理员） |
| **生产域边界** | 不建营收/结算/分红相关表；订单仅保留轻量**生产执行属性**（如关联种植标准版本），不做订单管理 |
| **现场数据接口** | 为智能体预留最新遥测、告警、地块权限查询接口（agent 不直连 MySQL），JWT 透传 + trace_id 贯穿 |
| **原始聊天记录** | CHAT_SESSION / CHAT_MESSAGE 正常建表落库（审计基线），智能体加工部分（RAG/上下文）由独立服务实现 |

## 三、前端建议（展示内容）

### 3.1 UI 风格定案：「田野绿 · 农业管理面板」

| 项 | 定案 |
|---|---|
| 整体基调 | 现代农业科技风：清爽、大信息块、高对比、卡片化 |
| 主色 | 主色 `#2E7D32`（深绿）、辅色 `#66BB6A`（亮绿）、数据面板深色底 `#1E293B`、告警橙红 `#E65100`（仅告警用） |
| 字体 | 大字号优先：基础 16px，大字模式 20px+，中文无衬线 |
| 布局 | PC：侧边导航 + 卡片网格；H5：底部导航 + 单列卡片流；同一代码库响应式 |
| 图表 | ECharts 统一绿色系主题 |
| 组件库 | Vue3 + TypeScript + Element Plus |

### 3.2 密度分级与页面模板（一套设计系统覆盖全部画像）

| 机制 | 说明 |
|---|---|
| **两级密度** | 标准密度（默认）/ 大字宽松密度（传统农户、雇工），切换 spacing/字号 设计令牌，同一组件库 |
| **三页面模板** | 看板模板（总览/报表）、任务模板（今日任务/清单）、表单详情模板（常规操作），经前端路由/布局层区分 |

### 3.3 画像 → 前端落点

| 画像 | 密度 | 页面模板 |
|---|---|---|
| 经验型传统农户 / 临时用工 | 大字宽松 | 任务模板（今日任务、步骤化、图标+文字） |
| 订单农户 | 标准 | 任务模板（任务清单、完成状态、标准对照） |
| 技术型新型农户 | 标准 | 看板模板（图表密集、实时、自定义布局） |
| 规模经营主体 / 农场管理员 / 村级监管者 | 标准 | 看板模板（多地块总览、生产报表、监管视图） |
| 系统管理员 | 标准 | 运维后台（审计、监控、配置） |

### 3.4 实现要点

- 风格令牌（颜色/字号/间距/圆角）在组件库主题中定义，切换依据用户 `ui_preference` 标签；
- 页面模板与权限模型解耦，仅按画像/路由区分；
- 展示内容仅覆盖**生产域**（遥测、告警、任务、标准对照），无财务/营收模块；
- 语言风格不进入前端文案，由 agent 上下文注入处理；前端仅保留全局字号设置（无障碍基础）。
